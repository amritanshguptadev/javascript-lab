## Description

This lab introduces the fundamentals of JavaScript development. The practical covers:

- Setting up a JavaScript development environment (HTML + JS)
- Creating and linking an external JavaScript file (`script.js`) to an HTML page
- Displaying output using three methods: `console.log()`, `alert()`, and `document.write()`
- Using Chrome Developer Tools (F12) to run commands in the Console
- Declaring variables using `var` for Name, Scholar Number, Semester, Course, and College Name
- Understanding JavaScript data types: **String**, **Number**, **Boolean**, **Undefined**, and **Null**, and inspecting them using `typeof`
- Printing a formatted student introduction via the Console
