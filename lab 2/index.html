Setup (10 min)

Two ways to run JavaScript today — try both once, then use whichever you prefer for the exercises.

Method A — Browser Console (fastest, no files needed)

  1. Open Chrome (or any browser) to a blank tab.
  2. Right-click anywhere → Inspect → click the Console tab. (Shortcut: F12, or Ctrl+Shift+J on Windows / Cmd+Option+J on Mac.)
  3. Type console.log("Hello, JavaScript!"); and press Enter.
  4. You should see Hello, JavaScript! printed below.

Method B — HTML + Script File (how real projects work)

  1. Create a folder named js-lab1 on the Desktop.
  2. Inside it, create two files: index.html and script.js.
  3. Paste the HTML below into index.html.
  4. In script.js, write: console.log("Hello from script.js!");
  5. Double-click index.html to open it in the browser, then open the console (F12) — the message should appear there.
<!DOCTYPE html>
<html>
<head><title>JS Lab 1</title></head>
<body>
  <h1>Open the console to see output (F12)</h1>
  <script src="script.js"></script>
</body>
</html>

Part 1 — Syntax Warm-Up (10 min)

Part 5 — Mini Project: Simple Grade Calculator (30 min)

Combine everything from today into one program. Use Method B (HTML + script.js).

Requirements:

  • Declare variables for a student's marks in 3 subjects (Numbers).
  • Calculate the total and the average using arithmetic operators.
  • Use a ternary operator (or nested ternaries) to decide a grade: average >= 90 → "A", average >= 75 → "B", average >= 40 → "C", else "F".
  • Use typeof to confirm your average variable is a Number.
  • Print a final summary line using string concatenation, e.g. "Total: 245, Average: 81.67, Grade: B".

Bonus: Add an isEligibleForScholarship Boolean using a logical AND of "average >= 85" and "attendance >= 75" (declare a sample attendance variable too).
